# WCAG 2.2 A/AA evaluation matrix

Date: 2026-10-11. Scope: complete `/projects/`, global chrome, seven enhanced panels and native fallback. Reviewer for every row: **Codex (agent)**. Criterion numbers refer to [WCAG 2.2](https://www.w3.org/TR/WCAG22/); the descriptions below identify this evaluation's checks. The 55 A/AA criteria are included; removed criterion 4.1.1 is excluded.

`PASS` is limited to the stated observation or inspected absence. `FAIL` would mean an observed unresolved defect. `NOT_EVALUATED` identifies a required missing human/browser check even where machine subchecks passed. No row or aggregate result is a complete conformance declaration. The desktop/mobile reader and author release gates remain open under [WCAG-EM evaluation principles](https://www.w3.org/WAI/test-evaluate/conformance/wcag-em/).

## Environment and evidence keys

- **A**: Playwright Chromium on macOS; 1366px and 390px enhanced states; static DOM at 390px; tags `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`, `best-practice`. [Axe receipts](axe-states.json).
- **K**: same browser, automated keyboard/mouse/emulated touch; native Chrome keyboard/tree smoke review. [Behavior tests](../../tests/features/projects.spec.ts), [review record](manual-review.md).
- **R**: Chromium 320×568, 390×844, 768×1024, 844×390, 1024×768, 1366×768, 1536×1024, 2560×1080 and 1366×400; 200% root text, spacing overrides and long labels. [Geometry](geometry.json), [screenshots](README.md#screenshots), behavior tests.
- **C**: computed CSS, source inspection and WCAG luminance calculation. [Palette](computed-palette.json), [ratios](contrast-ratios.json).
- **S**: inspected compiled HTML, source and rendered page. [Source manifest](source-manifest.json), [Nu response](w3c-nu.json), [machine checks](machine-results.json).
- **H**: physical desktop/mobile screen reader and actual browser zoom; unavailable result. [Exact remaining procedures](manual-review.md).
