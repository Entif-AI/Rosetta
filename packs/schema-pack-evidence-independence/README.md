# Evidence Independence Assessment v1

Status: proposed, fixture-only. This SchemaPack exports a governed extension, not a new Core kind or an accepted authority. It composes Source Substrate record and manifestation identities (#506), lineage references, bounded assessment and receipt references (#158), rights/retention (#1056) and correction/revalidation (#1560).

The bounded comparison names two subjects, a set or a named cluster. A stable assessment reference identifies that comparison; a content digest identifies one exact assessment revision. Record, manifestation, content digest and assessment identity are separate. Edges run from a descendant to a declared ancestor and carry explicit supporting evidence. A declared complete frontier requires exact subject identity and attributed ancestry. Unknown ancestry and unresolved references remain visible. No different hash, signature, publication venue or URL establishes independence by itself.

For a pair, established export followed by re-ingest of a shared Rosetta origin yields SELF_REFERENTIAL_LINEAGE. Direct syndication yields SYNDICATED; copy lineage or one stable record yields DERIVED_COPY. Shared declared ancestry yields COMMON_SOURCE unless a supported declaration of independent analysis distinguishes separate analyses of a shared dataset. That case yields PARTIALLY_INDEPENDENT. INDEPENDENT requires complete declared ancestry, no shared source and explicit supporting evidence of independent origins. Otherwise the outcome is INDEPENDENCE_UNKNOWN. A set or named cluster uses all member pairs: unknown takes precedence; homogeneous outcomes remain homogeneous; mixed known outcomes with independent or partially independent members yield PARTIALLY_INDEPENDENT; other heterogeneous dependence is unknown at the aggregate level. Pair-specific assessments remain separately inspectable.

The validator checks bounded metadata, reference closure, cycle freedom, contradictory declarations, revision digest and outcome. Assessment-local subject IDs do not create distinct origins: declared stable source-record aliases are traversed conservatively in common-source closure, while exact record-and-manifestation aliases can bridge explicit copy or export/re-ingest paths. Known ancestry cannot disappear merely because another manifestation of the same record was selected. Stable record identity alone cannot manufacture a particular export or re-ingest event. This is not universal identity resolution or a claim that every manifestation has the same bytes or exact revision. It does not authenticate external identities, receipts, rights, source discovery, independence declarations or completeness. A caller must resolve those through the owning authorities before relying on the assessment. The receipt attests a bounded assessment, not truth, authorization or a weight for evidence. Restricted evidence may be referenced without redistributing its bytes.

Corrections add a new content-addressed assessment revision with exact predecessor, correction and revalidation references and later observation time. The append-only history validator retains the prior assessment and comparison scope. No prior source bytes or historical conclusion are rewritten.

Conformance: use the workspace Pack validator for manifest and schema integrity and the executable schema package fixtures for semantic checks. Downstream research, evaluation and compatibility consumers must retain unknown and partial outcomes without adopting a weighting policy. Independent evidence authentication, Pack/harness acceptance and consumer adoption remain open.
