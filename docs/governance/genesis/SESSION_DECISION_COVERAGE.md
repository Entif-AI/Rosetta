# Genesis Session Decision Coverage Ledger

**Status:** Non-normative traceability companion  
**Date:** 2026-08-29  
**Applies to:** [`Genesis 0.4-draft`](../Genesis.md) and its companions  
**Primary semantic authority:** [`Rosetta v3.0.0 Core Spine Specification`](../../RFCs/Rosetta%20v3.0.0%20Core%20Spine%20Specification.md)

## 1. Purpose

This ledger records where the durable decisions reached during the 2026-08-28/29 Genesis design session live in the unified ruleset.

It exists to prevent a later synthesis from:

- truncating a decision because a newer draft used fewer words;
- preserving the idea under a competing name;
- copying the same rule into several authorities that can drift apart;
- promoting a project-specific preference into universal doctrine;
- mistaking an illustrative example for a Rosetta protocol artifact;
- silently retiring a rule without a disposition.

This file is not normative operating law. The linked Genesis section, companion, Rosetta authority, external standard, or project-local decision remains authoritative.

## 2. Coverage method

A session decision receives one of these dispositions:

| Disposition       | Meaning                                                                                         |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| **kernel**        | The concise cross-project rule belongs in `Genesis.md`.                                         |
| **companion**     | Durable detail belongs in one focused Genesis companion.                                        |
| **inherited**     | Rosetta v3 or an adopted external standard already owns the concept.                            |
| **project-local** | The decision belongs in a specific app, package, ADR, design specification, runbook, or README. |
| **deferred**      | Valuable future work, but not yet ready to become doctrine.                                     |
| **retired**       | The wording or mechanism was rejected, superseded, or found semantically unsafe.                |

One decision may have a kernel statement plus one companion elaboration. It should not have several competing normative homes.

Silence is not a disposition.
