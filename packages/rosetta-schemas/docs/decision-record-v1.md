# Decision record v1

**Status: proposed, fixture-only.** Source issue #1875. Schema owner: rosetta-schemas. Human semantic acceptance is outstanding. This is a governed extension composed with the Rosetta v3 Core Spine, source identity, authority envelope, temporal evidence and impact/revalidation. It creates neither a Core kind nor authority to act.

The immutable metadata record commits its complete canonical body to a SHA-256 record identifier. Stable decision/version references distinguish an evolving decision from a content revision. A source reference must carry an exact version or CID, a locator and a lineage; multiple representations of a source do not manufacture independent witnesses. Receipt references identify external attestations, not signatures made by this Profile. Author, controller, ratifier and authority evidence are distinct. A self-declared accepted state is insufficient for effective-state resolution.

The finite resolver accepts a declared locus, effective time, knowledge time, applicable scope references and exact ratification observations from their owner. The caller is responsible for authenticating those observations and resolving scope and authority; the resolver does not infer them. A clause reference is an explicit incompatibility coordinate within the locus. Different propositions at the same coordinate are incompatible unless an owning future contract provides a finer coordinate; additive propositions use independent coordinates. No topic index, file ordering, author rank or textual similarity defines a coordinate.

An unqualified later ratified incompatible proposition at the same exact controller/locus/scope replaces the prior proposition. An explicit relation targets exact record and clause references. Amendment and supersession affect only the named target; narrowing may remove named clauses; exceptions and temporary overrides apply only in the declared scope and time. A temporary override must end. Retraction and correction expose invalidation references for the existing revalidation owner. A missing, unauthorized, contradictory or unresolved target cannot effect a partial mutation. Peer conflict remains visible; equal effective times do not confer a tiebreak. The original history remains inspectable.

The resolver is a candidate semantic oracle over a supplied finite evidence graph, not a policy engine, storage authority or production decision executor. The producer must establish complete relevant history and actual ratification independently. Invalidation references require independent impact/revalidation before downstream reuse.

Executable conformance: governed-evidence-profiles.spec.ts covers the twelve issue fixtures and adversarial digest, authority, relation and scope cases.
