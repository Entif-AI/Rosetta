# Bounded GraphView v1

Public authority: #1728 under #1671, composing executable #1731/#1567 and #1730/#1560. Temporal roles remain #1558; source jurisdiction, memory-plane separation and support remain #315/#1219/#1221/#807/#1036. Core Spine Observation, lattice-edge and receipt references supply descent. `graph.view.v1` is a derived projection Profile, not a new Core kind. Public graph-query outcomes remain #1534; this Profile adds no query planner or completeness ontology.

The bounded descriptor records purpose/question, scope/source jurisdiction, construction Profile/version, admissible node families, recipe/source closure, attributed source lineages, active node/edge membership, evictions and inter-view relationships. `materialization` embeds materialized.view.v1 and owns identity, source frontier, temporal basis, rights/policy, transformation/dependency locks, digest and currency. No generic staleness vocabulary is duplicated.

The materialized artifact SHA-256 binds the canonical GraphView body excluding `materialization`; the metadata record ID remains the generic materialized-view identity. Arrays are the declared representation order. A reference here is not authentication of referenced bytes. Public conformance uses the published shape plus `parseGraphView`; supply the impact and materialized-view schemas when validating externally.

Active edge endpoints and lineage references must resolve within the descriptor. Node families must be declared. Every edge assertion is scoped to this view, whether copied from source or locally inferred. Support/provenance remains attributable; source-supported does not independently establish truth. Each view and inter-view relationship retains projection authority. W3C PROV `prov:wasDerivedFrom` is reused for actual derivation. `urn:rosetta:graph-view:overlaps` and `urn:rosetta:graph-view:meta-of` are namespaced descriptor relationships for shared membership and a view describing other views; they do not mint universal Core relationships or flatten source authority.

Evictions carry reasons, source lineage and explicit `preserved` source disposition. They remove active membership, never grant source deletion. Historical descriptors remain reconstructable through `appendGraphView`, which reuses additive generic view history and its revalidation rules. Inter-view references remain external; their owners validate their bytes and permissions separately.

`admitGraphViewReuse` delegates the current-rights decision and complete environment/frontier checks to the materialized-view owner. `graphViewIndependentSourceLineages` performs that admission before producing counts/identities. Multiple projections of the same declared source/CID must agree on witness lineage; a second projection cannot create independent corroboration. The source authority is responsible for resolving aliases and authenticating source identities. The helper reports declared lineages, not verified independent testimony.

Rebuildable descriptors identify a recipe, construction version and every source reference in their declared closure. Non-replayable descriptors must give attributable reasons. `verifyGraphViewRebuild` compares the exact declared source, environment, temporal and content closure. Its result proves descriptor replay only; it does not execute private construction policy, retrieve source bytes, establish semantic revalidation or grant refresh/write/promotion authority.

The focused fixtures cover shared execution/research sources, selective staleness, membership eviction with retained evidence, partial invalidation, overlapping/meta views, exact declared replay, non-replayability, lineage independence, rights revocation, invalid source deletion/Core promotion, dangling closure references and immutable history. No provider, graph engine, membership/pruning/ranking/retention algorithm or federation policy is standardized.
