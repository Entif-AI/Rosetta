# Compiled Context Artifact and blocks v1

Public authority: #1729 under #1488. Core Observation/receipt descent supplies attributable derived metadata; no Core kind or memory plane is created. Source identity/span/lineage remains #1036/#1068 and source-substrate authority; receipts #158, privacy #1056, write admission #994, safe hold #1295, identity-sensitive authorization #1296, referenced cache persistence #793, and rolling budget #1495 retain their owners. Withdrawn #1073 is not revived. Protected IPR-0027 owns selection, ordering, compression strategy, prefix promotion, cache planning, packing and fallback/reuse policy; none is implemented or required for public conformance.

`compiled.context.v1` 1.0.0 binds a canonical SHA-256 metadata identity to scope, intended consumer/task/thread/run, producer reference, ordered blocks, contradiction participants, omissions/availability, observed compilation mode/estimates, subordinate privacy/identity/safe-hold/cache/budget outcomes, creation and additive supersession. It describes an output package. `effectAuthority` is always `none`.

`compiled.context.block.v1` records a bounded block family, exact source identity/version/CID and span references, source lineage/provenance, policy/rights bindings, evidence/receipts, original/current authority and conflict classification, inline/reference payload, prefix/tail placement, estimates, compression outcome/Profile/preservation/loss, public reasons and freshness reference. Source-span semantics stay with their existing owner; no competing offset schema is invented. Artifact/block conformance uses the published shape plus `parseCompiledContext` / `parseCompiledContextBlock` respectively. Include the block schema when validating the artifact externally.

Original advisory/unknown/evidence/constraint classification cannot be promoted by packaging; a downgrade to advisory or unknown must declare a reason. Authority is independent of recency, placement and compression. Evidence-bearing blocks need evidence references. Original contradiction references survive transformation. Global conflicts preserve separately attributable participants; a current-rights/privacy exclusion may retain an opaque omitted participant and reason without exposing its payload. Missing participants and silent collapse fail admission.

Inline and reference representations are mutually exclusive. Applied compression identifies its Profile and preservation evidence; declined/restored outcomes give a reason. Loss, omission and unavailable sources remain inspectable. Unavailable sources cannot claim complete coverage. Deterministic/model-off partial coverage is valid. Estimates may be null; they are declared observations, not billing, quota, selection thresholds or guaranteed tokenizer results. Package estimates may include formatting overhead and are not forced to equal block sums.

`admitCompiledContextVisibility` requires the intended consumer/scope and a fresh supplied decision for every included source, with matching policy/rights references, strict boolean permission and a decision reference. Cached package claims do not grant that permission. `compiledContextSourceLineages` performs this admission before exposing counts/identities and shares the canonical source-alias invariant with GraphView. Multiple graph/vector/summary/context representations of one source remain one declared lineage. Referenced source/rights authorities must authenticate decisions, resolve aliases and enforce span-level restrictions; this Profile does not infer those facts from strings.

Safe-hold and cache/provider-prefix metadata remain subordinate outcomes, never effect or truth authority. Privacy/identity exclusions carry opaque outcome references rather than excluded content. Active safe hold requires its owner reference. `appendCompiledContext` retains immutable old metadata and explicit family/supersession links; historical bytes still need current rights before visibility. Ordering is the recorded output, with no private ranking, precedence or compression/cache procedure disclosed.

The fixture suite covers all nineteen required outcomes plus standalone block admission, malformed current permission, scope binding, immutable revisions and unknown estimates. Real provider/model/token/cost claims are not inferred from these synthetic conformance fixtures.
